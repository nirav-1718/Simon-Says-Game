# 🎮 Simon Says Game

A fun and interactive Simon Says memory game built using HTML, CSS, and JavaScript.

## 📌 About the Project

Simon Says is a memory-based game where the player must remember and repeat the sequence of colors shown by the game.

With each successful round, the sequence becomes longer and more challenging.

- 🎨 Interactive color buttons
- 🧠 Memory-based gameplay
- 📈 Increasing difficulty with each level
- 🎮 simple and responsive game interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🎯 How to play

1. press The **any key** to begin the game.
2. The game will flash one of the four colored buttons **white**.
3. remember the button that flashed.
4. Press the same button that game showed.
5. If your answer is correct, the game will moved to the next level.
6. At each new level, the game adds another button to the sequence.
7. If you press the wrong button, the **game is over**.
8. the game will display the **total level you reached**.
10. press **any key** to restart the game & try again.
